Этот документ описывает правила макро-стратегии и дипломатии.

1. Перемещение: скорость марша по гексам зависит от темпа. Осторожный шаг полезен для разведки, форсированный марш увеличивает дальность, но делает армию уязвимой для засад.
2. Экспедиции: отправка рабочих в ничью землю сулит огромную добычу ресурсов, но такие караваны идут без прикрытия — их можно перехватить и вырезать.
3. Дипломатия: связь не мгновенна. Гонцы с депешами идут днями; если их путь пересечет враг — письмо перехватят. Для надежных союзов нужен физический посол, чья жизнь всегда висит на волоске.

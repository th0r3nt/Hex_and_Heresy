# Hex & Heresy

**Hex & Heresy** — пошаговая глобально-тактическая стратегия (4X / TBS) в оригинальном сеттинге темного постапокалиптического фэнтези. Проект сочетает жесткую математическую симуляцию тактических и стратегических процессов с глубокой интеграцией больших языковых моделей (LLM) в качестве агентов, управляющих дипломатией, нарративом, генерацией снаряжения и принятием решений.

---

## Сеттинг и атмосфера мира

Мир пережил планетарную катастрофу — падение колоссального астероида «Прародитель», состоявшего из нестабильного внеземного минерала — **резонита**.

* **Магия как радиация:** магия не является даром богов. Это информационно-восприимчивая радиация изотопа резонита. Использование магии неизбежно загрязняет мир «первичной взвесью» — токсичным тяжелым пеплом, вызывающим мутации (проклятые гены) и экологический коллапс.
* **Долгая зима и нарушенное время:** кинетический удар замедлил вращение планеты. Сутки длятся 28 часов и разделены на две фазы: 16 *серых часов* (свет сквозь пепел, время для маршей и работы) и 12 *неоновых часов* (ночь с свечением пробитой магнитосферы, обостряющая агрессию мутантов).
* **Ничья земля:** пространство между укрепленными цитаделями фракций превратилось в геоаномалии, заваленные обломками цивилизации, радиоактивными кратерами и полями брани с тоннами неистлевшей стали.

## Ключевые особенности и механики

### 1. Архитектурная интеграция LLM
Языковые модели встроены непосредственно в геймплейный цикл и работают в рамках строгих контрактов (Pydantic-схем и вызовов функций):
* **Живая дипломатия:** общение с правителями других фракций строится на свободном текстовом вводе (депеши гонцами и личные аудиенции послов). Модели оппонентов обладают уникальными характерами и принимают механические решения (объявление войн, торговые соглашения, право прохода, вымогательство дани или казнь послов) через вызовы игровых функций.
* **Оружейная мастерская:** игрок может описать желаемый предмет текстом (например, «двуручная алебарда с прикрученным стволом аркебузы»). Оружейник валидирует идею на соответствие культуре фракции, рассчитывает баланс характеристик с учетом штрафов (вес, инициатива), формирует стоимость в золоте/материалах и добавляет рабочий чертеж в арсенал.
* **Летописец и Зал павших:** система собирает детальный математический срез каждого боя (потери, фланговые удары, переломы строя) и передает его летописцу. Нейросеть генерирует художественную летопись в культурном стиле фракции, а для павших именных отрядов и героев создает уникальные эпитафии, сохраняемые в базе данных.
* **Советник державы:** ИИ-советник между ходами анализирует экономику и внешние угрозы, приходя к игроку с инициативными предложениями и кнопками выбора (например, изменить налоговую ставку или нанять стражу в пограничный сектор).
* **Мастер игры (Game Master):** выступает арбитром вселенной, создавая кастомных персонажей по текстовой биографии игрока и генерируя динамические события (бунты при голоде, пепельные бури, рейды монстров).

### 2. Тактический бой (WEGO-симуляция)
Сражения происходят на прямоугольной сетке (от 14x14 до 20x20 клеток, где каждая клетка — участок 25x25 метров):
* **Фаза планирования и одновременный ход (WEGO):** обе стороны отдают приказы одновременно, после чего раунд (30 секунд боя) рассчитывается по строгому конвейеру: инициатива $\rightarrow$ фаза натиска $\rightarrow$ перемещение $\rightarrow$ стрельба $\rightarrow$ рукопашная $\rightarrow$ психология и среда.
* **Векторы атак и позиции:** направление взгляда отряда критично. Удар во фланг срезает 50% брони цели, а атака в тыл полностью игнорирует броню и наносит сокрушительный удар по морали.
* **Натиск и реакции:** отряды могут переходить на бег (темп x2.0). Защитник реагирует встречным натиском, попыткой бегства или удержанием строя на копьях (принятие удара обращает урон разгона против атакующего).
* **Геометрия поля и прямая видимость:** трассировка луча алгоритмом Брезенхэма, укрытия в лесах (снижение урона на 35%), блокировка выстрелов препятствиями и механика дружественного огня по союзникам на линии огня.
* **Обзор и темнота:** в неоновые часы видимость падает до 3 клеток, а пепельные бури и токсичный туман срезают ее еще на 1-3 клетки. Дальность оружия при этом не спасает: цель за пределом обзора остается непораженной.
* **Психология и окружение:** падение боевого духа ниже критического порога вызывает бегство отряда, провоцируя цепную панику соседних подразделений. Массовая гибель бойцов на одной клетке формирует труднопроходимую «гору трупов».

### 3. Глобальная стратегическая карта
* **Гексагональная карта из 271 гекса:** математически строгая сетка из 19 рядов с кубическими координатами $(q, r, s)$, ориентированная с севера на юг.
* **Зонирование территорий:** цитадели баз, лепестки союзных земель с ратушами и 257 нейтральных гексов Ничьей земли.
* **Маршевые темпы:** осторожный шаг (разведка), стандартный марш, конный рейд и форсированный марш (повышенная дальность, но гарантированная уязвимость к засадам).
* **Логистика и перехват:** гонцы с письмами и послы физически перемещаются по гексам карты. Вражеские армии в нейтральных зонах могут перехватить депешу, раскрыв планы отправителя.
* **Двухуровневый туман войны:** черный туман неисследованных земель, туман войны над разведанными гексами (ландшафт помнится, движение скрыто) и прямой обзор. Смотрят цитадели, города, ратуши, сторожевые вышки и сами армии - а пакт об обмене разведданными добавляет к обзору глаза союзника.

### 4. Модульная экономика и армия
* **Конструктор войск:** отряды формируются по принципу `Базовый архетип (расовое тело) + Оружие + Броня + Аксессуар`. Каждый компонент определяет характеристики, требования к содержанию и боевые теги (пороховое, тяжелое, серебряное, упор против натиска).
* **Управление рабочими:** рабочие отряды (тир 00) распределяются по уровням риска: безопасный труд в шахтах базы, добыча в союзных землях или рискованные экспедиции-караваны в нейтральные земли за богатыми жилами.
* **Налогообложение и настроения:** непрерывный ползунок ставки налога (от налоговых каникул до грабежа). Завышенные сборы вызывают забастовки рабочих и открытые вооруженные бунты в провинциях.
* **Мародерство и конверсия трофеев:** после боев на карте остаются поля брани. Разные расы утилизируют трофеи по-своему: люди переплавляют оружие мутантов в ресурсы веры, орки собирают кустарные бронелисты («спертые банки»), эльфы откачивают остаточный резонит из крови, а Паства поднимает из трупов бесплатные орды зомби.

### 5. Динамическое ветеранство
Изначально нанимаемые войска безлики. Однако при совершении тактического подвига (выживание при потере 90% состава, уничтожение опасных врагов или долгая служба под началом полководца) отряд получает статус **«Именного»**. Генерируется уникальная история, имя командира, черта характера и открывается диалоговое окно для прямого общения с отрядом (ветераны могут требовать повышенного жалования или отказываться от самоубийственных приказов).

## Игровые фракции

1. **Империя людей:** огнестрельное оружие, тяжелые рыцарские латы, доменные мануфактуры, полевые госпитали и инквизиция. Абсолютная, фанатичная нетерпимость к магии и мутациям.
2. **Зеленокожие:** механика толпы (бонусы к урону за численность отрядов в секторе), кустарная тяжелая броня из металлолома, боевые паровые фуры и прирученные пещерные огры.
3. **Эльфы:** долгоживущие кристаллизованные существа в парящих святилищах. Абсолютная инициатива стрелков, энергетические барьеры, антигравитационные ковчеги и сбор резонита с полей брани.
4. **Баронские войска:** независимые феодальные картели Ничьей земли. Глухая замковая оборона, тяжелые стрелки с павезами, сбор дорожных пошлин, долговые тюрьмы и армии наемников.
5. **Паства метеорита:** религиозный апокалиптический культ биоинженерии. Орды зомби, призыв плазменных демонов, вампиризм, рекурсивное возрождение всадников из склепов и жертвоприношения на алтарях.
6. **Вольные наемники:** мобильные контрактные роты, боевые дирижабли-корсары и дрессированные бронированные медведи.
7. **Нейтральные силы:** бродячие мародеры, шайки дезертиров, одичавшие стаи мутантов и толпы бунтовщиков.

## Архитектура проекта

Кодовая база спроектирована по принципам чистой слоистой архитектуры (Clean / Hexagonal Architecture) с жестким разделением ответственности. Границы слоев верифицируются тестами через разбор абстрактного синтаксического дерева (AST).

```
src/back/
├── l01_domain/          # Ядро бизнес-логики: чистые модели Pydantic, правила,
│                        # константы, исключения и протоколы (порты).
│                        # Не зависит от внешних библиотек и других слоев.
├── l02_services/        # Слой сценариев и оркестрации (Use Cases):
│                        # фасад ходов, FSM игрового потока, генератор мира,
│                        # дипломатия, экономика, летописец, мастер игры,
│                        # оружейник, сохранения.
├── l03_infrastructure/  # Адаптеры внешнего мира:
│                        # - LLM: клиенты OpenAI API, ротация ключей, сборка промптов;
│                        # - Databases: SQLite (SQLAlchemy + aiosqlite);
│                        # - GameData: загрузчик статических реестров игры.
├── l04_api/             # Слой доставки:
│                        # - HTTP: REST-роутеры команд игрока, Pydantic DTO;
│                        # - WS: WebSocket-канал событий мира через шину EventBus.
└── main.py              # Корень компоновки (Composition Root) и запуск FastAPI.
```

## Установка и запуск

### Требования
* Python 3.11 или выше
* Виртуальное окружение (`venv`)

### 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/your-username/llm_rts.git
cd llm_rts

python -m venv .venv
# Активация окружения:
# Linux/macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

pip install -r requirements.txt
```

### 2. Запуск тестового набора
Проект покрыт исчерпывающим набором модульных и интеграционных тестов (включая проверку инвариантов слоев, математики боя и контрактов API):

```bash
pytest src/back/tests/ -v
```

### 3. Запуск сервера бэкенда
```bash
python -m src.back.main
```
Сервер запустится по адресу `http://127.0.0.1:8000`.

* Интерактивная документация Swagger UI: `http://127.0.0.1:8000/docs`
* Канал WebSocket-уведомлений: `ws://127.0.0.1:8000/ws`

## Лицензия и статус разработки

Проект находится в стадии активной разработки (MVP). Разработка ведется по модульным этапам с соблюдением стандартов чистого кода и детальным документированием механик.

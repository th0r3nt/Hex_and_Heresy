# Hex & Heresy

**Hex & Heresy** - это пошаговая глобально-тактическая стратегия, сочетающая элементы 4X, сеточные тактические сражения и ролевое взаимодействие с использованием больших языковых моделей (LLM). Проект находится на стадии разработки минимально жизнеспособного продукта (MVP).

---

## Общая концепция и мир игры

Действие разворачивается в оригинальном сеттинге темного постапокалиптического фэнтези. В эпоху «Долгой зимы» остатки цивилизаций выживают на планете, пострадавшей от падения космического тела «Прародитель». 

Катастрофа изменила физические константы Земли:
* **Астрономические сдвиги:** Сутки растянулись до 28 часов, разделившись на безопасные *Серые часы* и психологически нестабильные *Неоновые часы*, подсвеченные остаточной радиацией.
* **Магическая радиация:** Магия представлена изотопом *Резонитом* - информационно-восприимчивой материей. Ее использование приводит к биологическим мутациям («проклятым генам») и засорению атмосферы токсичной пылью («первичной взвесью»).
* **Географические зоны:** Игровой мир разделен на защищенные Цитадели (базы), прилегающие союзные земли и аномальные нейтральные регионы (Ничьи земли), где сокрыты ресурсы и артефакты ушедших эпох.

## Архитектура системы

Проект разделен на два изолированных уровня взаимодействия для предотвращения рассогласования игрового состояния:

```
┌────────────────────────┐              ┌────────────────────────┐
│   Frontend (Electron)  │ ◄── JSON ──► │    Backend (Python)    │
│  - "Глупый терминал"   │              │  - Игровая логика      │
│  - Отрисовка UI / DOM  │              │  - Асинхронные LLM API │
│  - Сетка и анимация    │              │  - Валидация Pydantic  │
└────────────────────────┘              └────────────────────────┘
```

1. **Backend (Python):**
   * Обрабатывает математику сражений, перемещения, экономические расчеты и циклы ходов.
   * Опирается на строгое определение типов и валидацию состояния мира (`WorldState`) через библиотеку `Pydantic`.
   * Асинхронно взаимодействует с внешними API больших языковых моделей, исключая блокировку основного потока выполнения при генерации текстовых ответов.
2. **Frontend (TypeScript/JS, CSS, HTML в Electron-контейнере):**
   * Функционирует по принципу «тонкого клиента». Принимает структурированные JSON-данные от бэкенда и обновляет состояние интерфейса.
   * На этапе MVP задействует текстовые символы, эмодзи и CSS-стилизацию для отрисовки гексагональной карты и тактической сетки.

## Основные игровые механики

### 1. Текстовая дипломатия и ИИ-полководцы
* **Модульная сборка промптов:** Личность каждого компьютерного оппонента генерируется динамически с помощью скрипта-конструктора. Промпт объединяет общие правила поведения, особенности расы, базовые шаблоны действий и специфический архетип (например, *Стратег*, *Параноик* или *Разжигатель войны*).
* **Свободный ввод сообщений:** Общение с ИИ-лидерами реализовано через текстовые депеши и послов на глобальной карте. Модели принимают свободный ввод игрока и реагируют в соответствии со своими характеристиками.
* **Управление через JSON:** Ответы моделей содержат инструкции в формате JSON. С помощью инструментария *Function Calling* ИИ выполняет реальные игровые действия: объявляет войну, предлагает обмен ресурсами или требует дань.

### 2. Тактические сеточные бои
* **Тактическое поле:** Бой симулируется на прямоугольной сетке $20 \times 20$ клеток, где каждый отряд занимает одну позицию.
* **Физика и позиционирование:** Система рассчитывает скорость перемещения, выносливость, направление ударов (фланг, тыл) и урон от натиска, зависящий от разницы скоростей сталкивающихся отрядов.
* **Факторы ландшафта и окружения:** На тактическое преимущество влияют возвышенности, грязь, болотистая местность, ночное время суток и погодные условия (например, дождь, препятствующий использованию порохового оружия).
* **Горы трупов:** Массовая гибель отрядов на конкретном участке тактического поля деформирует ландшафт, создавая завалы из тел, снижающие скорость передвижения и дающие новые тактические возможности некромантам.

### 3. Экономика и сборка войск
* **Управление рисками:** Распределение рабочих (юнитов 00 уровня) между безопасной добычей ресурсов на базе, умеренно опасной работой в союзных землях и экспедициями в нейтральные зоны.
* **Конструктор экипировки:** Характеристики боевых отрядов формируются на основе их базовой расовой основы, выбранного оружия, типа брони и дополнительных аксессуаров.
* **Мародерство:** После сражений уцелевшие отряды или рабочие могут собирать оставленное на поле боя снаряжение. Трофеи конвертируются по фракционным правилам: люди могут переплавлять чужую экипировку на ресурсы или очки веры, зеленокожие модифицируют её под свои стандарты, а наемники продают на черном рынке.

### 4. Конструктор снаряжения («Оружейный мастер»)
* Уникальный внутриигровой интерфейс позволяет описывать желаемое снаряжение обычным текстом. 
* Модель оружейника анализирует запрос на соответствие лору фракции, рассчитывает сбалансированные характеристики, присваивает тир, рассчитывает стоимость производства в материалах и создает новую карточку снаряжения, доступную для экипировки отрядов фракции.

### 5. Развитие юнитов и система ветеранства
* При найме базовые отряды представляют собой неперсонализированные боевые единицы без интеграции с LLM.
* При совершении ключевых тактических достижений (выживание при критических потерях, уничтожение элитного юнита, захват цитадели) отряд получает статус **именного**.
* Для именных отрядов генерируется личность командира, предыстория подвига и уникальные черты характера. Игрок получает возможность напрямую общаться с ветеранами, которые могут требовать повышения жалования, отказываться от невыгодных тактических маневров или запрашивать специфическое снаряжение.

## Игровые фракции

| Фракция | Особенности геймплея | Технологический упор |
| :--- | :--- | :--- |
| **Люди (Империя)** | Жесткая дисциплина, использование ополчения. Не переносят магию. | Регулярная армия, пороховое оружие, инквизиция. |
| **Зеленокожие** | Высокая численность, механика толпы (бонусы за количество союзников). | Кустарная инженерия, шаманизм, приручение диких монстров. |
| **Эльфы** | Высокая инициатива и стоимость отрядов. | Кристаллическое оружие, иллюзии, сбор резонита с павших. |
| **Баронские войска** | Экономическое давление, сбор пошлин с нейтральных территорий. | Оборонительные замки, арбалеты, тяжелые латы. |
| **Разбойники** | Жертвенные механики, отсутствие понятия ценности жизни. | Некромантия, призыв демонов, манипуляции с телами павших. |
| **Наемники** | Уникальные контракты на глобальной карте, высокая мобильность. | Воздушные дирижабли, профессиональная тяжелая пехота. |

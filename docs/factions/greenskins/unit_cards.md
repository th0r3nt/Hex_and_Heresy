* Тир 03:
    - Спертый мушкет (2H, 6 кв.).
    - Шаманский посох с черепом (2H).
    - Украденные метательные бомбы (2H).
* Тир 04:
    - Вырванное дерево (2H). Только для огра.
    - Ржавый якорь (2H). Только для огра.
    - Огромная дубина (2H). Только для огра.
* Тир 05:
    - Секира из метеорита (2H). При каждом убийстве восстанавливает выносливость отряда.

## Аксессуар
Занимает вторую руку, если основное оружие - одноручное (1H).
* Тир 00:
    - Доска с гвоздями (щит).
    - Горсть гнилых грибов.
* Тир 01:
    - Украденный ростовой щит.
    - Сеть мародеров. В начале ближнего боя отряд кидает сети.
    - Одноручный топор. 
* Тир 02:
    - Барабан племени.
    - Связка "Красных мухоморов". 
* Тир 03:
    - Стекляшка-прицел.
    - Амулет безумия.
    - Лебедка с резинкой (2H, 3 кв.). Подручные гоблины натягивают жгут из кишок монстров. Позволяет запускать... бойцов отряда, к которому прикреплены.
* Тир 04:
    - Гоблин-наводчик в корзине (только для огров).
* Тир 05:
    - Трофейный штандарт ммперии. Снижает содержание всей армии в золоте (орки просят меньше денег, когда есть такая слава).
* Тир 06:
    - Очаг спор. Все убитые вражеские юниты вокруг карточки имеют шанс 15% воскреснуть как "Зомби-грибы" на стороне игрока.

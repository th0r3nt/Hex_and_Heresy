Советник находится в верхнем правом углу меню игры. Он работает только в том случае, если игрок включил его в настройках.

К советнику специально подключается LLM, которая каждый ход будет генерировать универсальные сообщения игроку.
Советник будет в уникальном стиле в зависимости от расы.

Есть как заготовленные архетипы, например, советник "Шаман" от зеленокожих, "Инквизитор" от людей. Игрок может создавать своих кастомных советников: прописывая и сохраняя промпт для их личности.

Пример сообщения от советника:
* "Инквизитор" (люди): "Мой лорд, на границах замечена ересь. Я настаиваю на увеличении налогов для финансирования очистительных костров." (рядом с сообщением появляется окно "Повысить налоги на 10%? Да/Нет)

Каждый советник может проводить действия за игрока - например, нанять стражу для одного из графств или повысить налоги. Это крайне полезно в лейтгейме. В начале игры игроку должен быть интересен менеджемент каждого здания и отряда, но в конце с кучей зданий микроменеджемент успевает наскучить.

Технически это можно реализовать через навыки function calling. Каждое из предложений советника будет состоять из:
    Окна - JSON схема, в которой советнику (LLM) обязательно нужно ввести следующий JSON схемы:
        - поле "Описание предложения" (например, "Повысить налоги на 10%?");
        - итоговый выбор (например, "Да" "Нет" "Повысить на 5%")


Если игрок, например, принял предложение "Повысить налоги на 5%" или любое другое, бэкэнд автоматически вызывает новый запрос к советнику LLM с надписью "Игрок выбрал выбор X, проведите сооветствующие действия". 

И уже советник будет вызывать навыки.
 например: 
    change_taxes(number_of_percent: int, action: Union["decrease", "increase"])
    ... и другие.

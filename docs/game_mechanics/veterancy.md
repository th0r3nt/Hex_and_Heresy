
# Ветеранство отрядов
Если у каждого отряда крестьян с вилами будет своя сложная личность с первого хода, игра превратится в визуальную новеллу, а бюджет на токены API испарится за пару часов. 
В мире Hex & Heresy личность нужно *заслужить*. При найме любая карточка - безликое пушечное мясо. У них есть только статы и стандартные фразы-заглушки. LLM к ним не подключается. 

Но если этот безымянный отряд совершает на тактическом поле боя "Подвиг", срабатывает триггер "Повышение". Отряд обретает статус «Именного». Начиная с этого момента, отряд получает собственную карточку лора, сгенерированную нейросетью, и возможность прямого текстового диалога с игроком.

## Условия срабатывания
Python-бэкенд после каждого боя проверяет статистику выживших отрядов. "Повышение" происходит автоматически, если выполнено одно из условий:

### Реализовано

* Последний рубеж: 
    Отряд пережил бой, но потерял 90% личного состава (осталось ≤10% от исходной численности архетипа) — становится кандидатом сразу по факту боя.
* Кровавая жатва: 
    Изначальная идея "MVP одного боя" заменена персистентным счётчиком: каждый убитый юнит начисляет отряду вес по своему габариту (мелкий — 1, средний — 2, крупный — 4, огромный — 8: убить огра стоит как восьмерых крестьян), вес копится между боями, не сбрасываясь после победы. При достижении суммарного веса 500 отряд становится кандидатом.
* Выслуга лет: 
    Отряд, состоящий в армии под командованием полководца (у армий без полководца — гарнизонов, безхозных отрядов — выслуга не идёт, см. commanders.md), каждый глобальный такт копит игровые сутки службы. При достижении 60 суток (≈2 игровых месяца — сама длительность месяца лором не определена, взята условно) становится кандидатом. Не зависит от того, участвовала ли армия в бою в этот конкретный такт.

### Только в лоре, не реализовано

* Давид и Голиаф: 
    Отряд низкого тира (00-01) нанес смертельный удар отряду элиты (03-04) или вражескому полководцу.
* Сокрушители стен:
    Отряд нанес последний удар, разрушивший вражескую цитадель.

Оба пункта требуют отслеживания конкретного финального удара по конкретной цели (кто и что именно добил), а не просто накопления урона/времени — для этого пока нет ни модели данных, ни хука в боевом конвейере.
## Процесс генерации
Как только триггер сработал, бэкенд формирует скрытый запрос к системной LLM, передавая контекст подвига.

Пример системного контекста:
> *"Раса: Люди. Юнит: Ополченцы с арбалетами (Тир 01). Подвиг: В одиночку расстреляли вражеского Огра (Тир 04), пока рыцари отступали. Сгенерируй им уникальное имя командира, название отряда, 1 черту характера и 1 сбалансированный механический бафф."*

Пример ответа LLM:
```json
{
  "commander_name": "Маркус",
  "squad_nickname": "Грязные стрелки Маркуса",
  "trait_name": "Высокомерные",
  "lore_description": "Они смотрели, как элитная кавалерия бежит в страхе, пока сами, по колено в грязи, перезаряжали арбалеты. Теперь они знают цену дворянству.",
  "mechanical_modifier": {
    "stat": "morale",
    "value": 2
  }
}
```


## Влияние на геймплей
После повышения карточка визуально меняется (получает золотую рамку/иконку короны). 

### Вкладка "Диалог"
У карточки открывается текстовое поле для общения. Командир (в текущем примере Маркус) получает собственный системный промпт, в который вшита память об их подвиге и сгенерированная черта ("Высокомерный").

### Самоуправство
Именные отряды перестают быть безвольными рабами. 
Через Function Calling в диалогах они могут выдвигать требования:
    * Повысить им жалование (`upkeep_gold +20%`). Если игрок откажет, они получат дебафф к морали.
    * Отказаться вступать в бой или идти в авангарде (сошлются на старые раны или несогласие с тактикой).
    * Попросить уникальную экипировку у Оружейного мастера.

### Смерть ветеранов
Смерть безымянного пушечного мяса накладывает стандартный штраф -1 к Морали соседним клеткам на тактическом поле.
* Но если на поле боя погибают ветераны (например, *"Грязные стрелки Маркуса"*):
    - Это наносит большой моральный шок всей армии (соседние отряды могут мгновенно впасть в панику).
    - В логе Глобальной карты появляется красное уведомление (на одном из гексагонов): *"Легенда пала. Грязные стрелки Маркуса были уничтожены отрядом 'Орки-кромсатели'."*
    - Погибший отряд навсегда заносится в "Зал павших" (отдельное меню на Базе), где игрок может прочитать историю всех своих погибших ветеранов, их подвиги и дату смерти.

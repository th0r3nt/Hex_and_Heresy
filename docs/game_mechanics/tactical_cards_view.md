
Представим отряд на тактической карте как фоновое изображение (сама карточка) + рамка вокруг неё:

```text
┌────────────────────────────────────────────┐
│ [Оружие] [Броня] [Аксессуар]         (Тир) │
├────────────────────────────────────────────┤
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│              Арт базового юнита            │  <- Фоновый арт
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
│                                            │
├────────────────────────────────────────────┤
│ Аркебузиры                                 │
│ Численность:  [████100███]                 │
│ Мораль:       [████85███ ]                 │
│ Выносливость: [████100███]                 │
└────────────────────────────────────────────┘
```


На тактической карте рамка по умолчанию отключена (видно только численность и значок морали в виде красной, оранжевой или зеленой отметки), 
но как только игрок наводит мышью на карточку - появляется рамка с детальной информацией.
